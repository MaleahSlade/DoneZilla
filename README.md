DoneZilla is a to-do app built for the people who crush goals the way kaiju destroy cities. The app leverages React’s Context API to manage various aspects of the application’s state. This includes managing the list of to-dos, current visibility filters, and a simple theme. My favorite part of this app is how I used emojis instead of text for part of the dark/light mode logic, not just in the visible user interface. When you click on the moon and sun, the eyes flick from one side to the next. Is this a best practice? I'm sure it is not. However, it was a fun discovery, and I will probably do some more fun stuff with emojis in code in the future.
