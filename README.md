DoneZilla is a to-do app built for the people who crush goals the way kaiju destroy cities. The app leverages React’s Context API to manage various aspects of the application’s state. This includes managing the list of todos, current visibility filters, and a simple theme. My favorite part of this app is how I used emojis for some of the coding logic. Is this a best practice? I'm sure it is not. Howver, it was fun discovery and I will probably do some more fun stuff with emojis in code in the future.
